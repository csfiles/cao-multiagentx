# SupportMesh Returns Policy

## Overview

SupportMesh offers a flexible returns policy designed to ensure customer satisfaction across all product categories and service tiers.

## Return Windows by Customer Tier

- **Standard tier**: 30 days from delivery date
- **Premium tier**: 60 days from delivery date
- **Enterprise tier**: 90 days from delivery date

All return windows are calculated from the confirmed delivery date recorded in the order system.

## Eligible Return Reasons

Returns are accepted for the following reasons:

- **Damaged item**: Item arrived physically damaged, broken, or defective due to shipping. Full refund eligible.
- **Wrong item**: Customer received an item different from what was ordered. Full refund or exchange eligible.
- **Defective product**: Item stopped working within the return window due to a manufacturing defect. Full refund eligible.
- **Not received**: Package shows delivered but customer did not receive it. Full refund after investigation.
- **Not satisfied**: Customer is unsatisfied with the product for any reason. 50% refund eligible within return window.

## Items Not Eligible for Return

The following items cannot be returned:

- Digital downloads or software licenses after activation
- Customised or personalised items
- Perishable goods (food, flowers)
- Hazardous materials
- Items returned after the applicable return window has expired

## Return Process

1. Contact customer support with your order ID and reason for return
2. Customer support will assess eligibility and calculate the refund amount
3. If eligible, a refund request is prepared for review
4. Approved refunds are processed within 3–5 business days
5. Refunds are issued to the original payment method

## High-Value Returns

Refund requests over $500.00 require manager approval before processing. Enterprise tier customers may have dedicated account managers for high-value returns.

## Exchanges

In lieu of a refund, customers may request an exchange for an equivalent item. Exchanges are processed at no additional shipping cost for Premium and Enterprise tier customers.

## Shipping Costs for Returns

- Standard tier: Customer pays return shipping
- Premium tier: Free return shipping label provided
- Enterprise tier: Free return shipping with priority pickup scheduling
